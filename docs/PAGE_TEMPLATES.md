## Affiliate article

H1 → disclosure → quick verdict → evidence → comparison/buy box → article content → related decision links → optional service fallback → methodology.

## Hybrid problem article

Problem diagnosis → DIY path → product guidance → when professional help makes sense → contextual service CTA → FAQ.

Service overview → price factors → provider checklist → demo form → consent/no-storage notice → FAQ. Do not overload service pages with affiliate buy boxes.

## Comparison page

Verdict → side-by-side table → evidence/limitations → product CTAs. Keep the conversion focused on product selection.
