# PetHomeScout Information Architecture

## Root hubs

```text
/family-home/
/smart-tech/
/cleaning-odor/
/services-insurance/
```

Articles use flat root URLs. No `/us/`, `/au/`, `/blog/`, or `/category/` path is part of the approved MVP.

## Decision path

```text
Hub → Problem → Breed/household context → Product/comparison → Tool → Service fallback
```

The four hubs remain distinct. Cross-hub CTAs are contextual, manually selected, and secondary to the page's primary search intent.
