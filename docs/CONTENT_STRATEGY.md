# PetHomeScout Content Strategy

## Editorial model

Build people-first, evidence-labeled US-English content around four hubs:

`/family-home/` · `/smart-tech/` · `/cleaning-odor/` · `/services-insurance/`

Every article should solve a specific household decision, not target a broad keyword by itself.

## Hyper-niche context

Use the Article ACF fields to describe the decision context: user intent, pet type, breed, hair length, shedding level, floor/carpet type, home size, children, problem type, product category, primary hub, evidence, and last review date.

Example angles:

- Robot vacuum for Golden Retriever hair on thick carpet.
- Self-cleaning litter box for a 15 lb Maine Coon.
- Air purifier for cat-litter odor in a small apartment.
- Pet insurance factors for French Bulldogs in Texas.

Do not mass-generate breed, city, or state pages. Publish only when the page adds original decision logic, evidence, or a useful tool.

## Page hierarchy

Hub → problem guide → comparison/product guide → decision tool → contextual service page.

Affiliate CTA is primary on affiliate pages. Service fallback is secondary and must be explicitly enabled in ACF.
